# 成长答卷

从小满还是婴儿带到高中。四个时期，每个时期只能安排两次，学识和心情都会通向结局。

## 怎么跑

需要已安装 [Node.js](https://nodejs.org/) 20 或更新版本。在本文件夹打开终端，逐行执行：

```bash
npm install
npm run dev
```

浏览器打开终端里显示的本地地址，一般是 `http://localhost:5173`。

给评审的可运行产物在 `dist/`。生成并打开它：

```bash
npm install
npm run build
npm run preview
```

不要双击 `dist/index.html`。浏览器不允许网页用这种方式读取本地模块，会白屏。请用上面的命令。

## 怎么玩

| 操作 | 作用 |
| --- | --- |
| 鼠标点击活动 | 花 1 点精力，属性立刻变化 |
| 键盘上方的 1 到 5 | 与从左到右的活动按钮相同 |
| Enter | 结束这个时期 |
| Esc 或「暂停」 | 暂停、重开或回主菜单 |

胜利：

- 「准时开饭」：学识至少 70，心情至少 45，压力不超过 72。
- 「球场比奖状响」：学识在 32 到 69 之间，心情至少 68，压力不超过 60，体质至少 52。

失败：

- 压力达到 90，或心情降到 20 及以下。
- 学识至少 80，同时心情不超过 48 或压力达到 76。
- 其余情况，视为没准备好高考。

判断顺序写在 `src/data/endings.js`，靠前的规则先生效。高中结束后可以立刻再来一局。

## 已实现

- 主菜单、加载、四个时期（婴儿、幼儿园、初中、高中）、暂停、本地单存档、高考、五种结局和重开。
- 每个时期有自己的五件活动，结束时有一件二选一。活动会随时期换成下一组。
- 键盘和鼠标都能玩。

## 已知问题

- 还没有原创人物立绘和音效。四个时期暂时用不同的表情符号区分年龄。
- 标题画面有「开始游戏」「存档」「退出」。只有一个存档格，开始新的一局会先问要不要盖掉它。
- 孩子名字固定为「小满」，改 `src/config/constants.js` 里的 `CHILD_NAME`。
- 窄屏只会整页缩小，没有单独的竖屏界面。
- 盲测还没做，见 `DESIGN.md` 第④节。`REVIEW.md` 要等你亲自试玩同学的作品后再写。

## 我做的那个决定

人生拉成四个时期，而不是按天排课，也不是只做小学六年。每个时期只有 2 点精力，活动表整个换掉。少了逐日细节，换来几分钟内一定能从婴儿玩到高考，而且每个时期都在做不同的取舍。

## 素材与引用来源

- 画面：程序绘制的矩形和系统文字，没有外部图片。
- 字体：玩家电脑自带的微软雅黑、苹方或 Noto Sans SC，仓库里没有字体文件。
- 表情符号：系统自带。
- 引擎：[Phaser 3](https://github.com/phaserjs/phaser)（MIT）。
- 构建：[Vite](https://github.com/vitejs/vite)（MIT）。
- 类型参考了「家长培养」这一类游戏。角色名、文案、数值和画面都是原创，没有使用《中国式家长》的名称、剧情、数值或美术资源。

## 想自己改（给作者）

平时只改这些文件，不必先动场景：

- 某个时期有哪些活动：`src/data/stages.js` 里的 `actionIds`
- 活动效果：`src/data/actions.js`
- 事件：`src/data/events.js`
- 结局门槛：`src/data/endings.js`
- 每个时期几次安排、开局数字：`src/config/constants.js`

改完可以运行 `npm run check`。它会用四条固定玩法走完四个时期，看结局有没有被改坏。

作者的学号和姓名确定后，把整个文件夹改名为 `学号_姓名_成长答卷`。
