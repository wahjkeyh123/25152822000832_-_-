# 成长答卷

给孩子取个名字、选男孩或女孩，从婴儿带到高中。一共 24 个回合（婴儿 3、幼儿园 4、小学 5、初中 5、高中 7），每回合排 6 件事；父母满意度和孩子压力两条线都要看住，最后按七项属性决定孩子去向。

## 怎么跑

需要已安装 [Node.js](https://nodejs.org/) 20 或更新版本。在本文件夹打开终端，逐行执行：

```bash
npm install
npm run dev
```

浏览器打开终端里显示的本地地址，一般是 `http://localhost:5173`。

给评审的可运行产物在 `dist/`。生成并打开它：

```bash
npm install
npm run build
npm run preview
```

不要双击 `dist/index.html`。浏览器不允许网页用这种方式读取本地模块，会白屏。请用上面的命令。

## 怎么玩

1. 「开始游戏」→ 输入名字（最多 6 个字）→ 选男孩或女孩 → 「开始养育」。
2. 每个时期开头有一屏过场，显示这个时期的孩子形象和回合数。婴儿 3、幼儿园 4、小学 5、初中 5、高中 7。
3. 每回合：
   - 右边花悟性学技能（悟性没有上限；幼儿园认字数数，小学语数英体美，往后分科）；
   - 左边「安排」里排 6 个，或者「照上回合再排一次」，在这个面板里按「结束本回合」；
   - 点画面中间的孩子进脑洞，每回合固定挖 6 次，点哪一项只加哪一项（面子、魅力不在格子上）。
4. 小学起「商店」开门：两样减压的玩具、两样讨父母欢心的东西（每回合每样限买一次）。八本职业书要到初中才能买。
5. 按「结束本回合」之后会弹出一件当天的事，每回合都有。学得狠、压力高、找过同桌，碰到的事会不一样。
6. 初中出现同桌林舟，左边「朋友」可以每回合找一次。初中选方向，高中选职业。高考后看七项属性够上哪个职业。

| 操作 | 作用 |
| --- | --- |
| 鼠标 | 所有按钮、孩子、脑洞格子 |
| 键盘 1 到 5 | 把第 1~5 个会的技能排进本回合 |
| Enter | 结束本回合 |
| Esc 或「暂停」 | 暂停、重开或回主菜单 |

顶栏两条线：

| 情况 | 结果 |
| --- | --- |
| 压力到 100 | 「心力交瘁」3 回合：加的属性减半，精力少回 |
| 压力到 0 | 「无忧无虑」2 回合：脑洞每格多 2，精力多回 |
| 父母满意度到 100 | 随机两三项属性 +4~8、积蓄 +30~50，「家里和睦」3 回合，满意度回到 60 |
| 父母满意度到 0 | 「家里冷冰冰」2 回合：每回合压力 +4，满意度回到 20 |

结局：志向职业够格是「说到做到」，别的职业够格是「换了一条路」，都不够是「还没想好的明天」。高考时压力 90 以上或心情 20 以下，直接算崩溃。

## 已实现

- 主菜单、取名和选性别、五个时期的过场、暂停、本地单存档（刷新页面能接着玩）、高考、八种职业结局和重开。
- 五个时期各有一张白天的背景；男孩、女孩在五个时期各有一张形象，中间的孩子、左上角头像、个人信息和结局证书都会跟着换。
- 回合制、父母满意度、压力与四种状态、商店道具、每回合一件当天的事、初中同桌林舟、每期期望。
- 键盘和鼠标都能玩。

## 已知问题

- 只有一个存档格，开始新的一局会先问要不要盖掉它。
- 窄屏只会整页缩小，没有单独的竖屏界面。
- 背景音乐已放入 `assets/audio/bgm.mp3`。其余音效也放同一目录就会自动加载（见那里的说明）。当前还缺 `cloud`、`stage`、`ending`。
- 盲测还没做，见 `DESIGN.md` 第④节。`REVIEW.md` 要等你亲自试玩同学的作品后再写。

## 我做的那个决定

结局看七项属性够上哪个职业，而不是只看高考分。这样「学什么技能、买哪本书」才有方向。压力和满意度两条线负责拉住玩家：只往上推会心力交瘁，只讨父母欢心孩子会累垮。

## 素材与引用来源

- 背景和孩子形象：作者先用豆包生成参考图，再在 Cursor 里用 AI 生图重画成无人物背景和白底人物，详见 `AI_USAGE.md`。
- 图标：`assets/images/icons/` 里的 png，加载时自动裁掉白边。
- 道具、按钮、面板：程序绘制。
- 字体：玩家电脑自带的微软雅黑、苹方或 Noto Sans SC，仓库里没有字体文件。
- 背景音乐：Freesound《Home - Romantic Piano》（CC0），循环钢琴，https://freesound.org/people/deleted_user_14795591/sounds/679165/
- 引擎：[Phaser 3](https://github.com/phaserjs/phaser)（MIT）。
- 构建：[Vite](https://github.com/vitejs/vite)（MIT）。
- 类型参考了「家长培养」这一类游戏。角色、文案、数值和画面都是原创，没有使用《中国式家长》的名称、剧情、数值或美术资源。

改完可以运行 `npm run check`。它会用四条固定玩法走完 24 个回合，看四类结局有没有被改坏，并抽查脑洞、商店和两条线的规则。
